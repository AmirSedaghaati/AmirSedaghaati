## Amir Sedaghati

My background is wet-lab first — MSC culture, ELISAs, the whole manual pipeline. I moved into computational work because the data volumes stopped being manageable by hand. Now I build the automation that connects both sides.

---

### How I work

The workflow pipeline is as follows-filter the libraries using RDKit (Lipinski, ADMET), pass to AutoDock Vina and parse/rank the output in pandas. For dynamics, I use GROMACS then postprocess in MDAnalysis/MDTraj, producingRMSD/RMSF plots using matplotlib and investigating structures in PyMOL, as well as using R/ggplot2 for publication quality statistics. Connective tissue (PubChem lookups, pushes to shared sheets, laboratory database pushes) are all automated in n8n.

### Selected results

Engineered human Wharton's jelly MSCs using a lentiviral vector to express EPO in a 4T1 breast cancer mouse model.
Maintained therapeutic levels of plasma EPO, Hb, and Hct for >10 weeks post-transplantation.
Published: [Current Gene Therapy](https://doi.org/10.2174/1566523222666220405134136)

Docked walnut husk metabolites against pectate lyase Pel3 using AutoDock Vina. Aesculin ranked first at −6.39 kcal/mol.
Published: [Biochemical and Biophysical Reports](https://doi.org/10.1016/j.bbrep.2025.102171)

Screened the compound libraries in parallel against MAO-A, Synapsin I, and Synapsin II.
Selected 12 multi target hits and optimized using the pharmacophore models.
Status: Manuscript under review — Scientific African
